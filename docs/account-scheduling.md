# 账号启停、自动冷却与模型限额

## 单独关闭账号

在供应商的账号列表或账号详情中切换 **启用账号**。关闭后不再参与轮询，也不能通过首选账号、模型映射或旧会话绑定绕过。已经绑定其他账号的对话不会擅自迁移，以免丢上下文或串号。

**手动开关、凭据状态、自动冷却是三个独立状态。**

- 手动关闭：只有你再次开启后才参与调度。
- 凭据过期/错误：冷却结束不会把失效凭据改为有效。
- 自动冷却：到达供应商返回的恢复时间后清除冷却；只有手动开关已开启且凭据有效的账号才恢复调度。

开关和冷却均持久保存；退出或重新部署应用不会清除冷却。运行时到期会通知界面更新；启动及选择账号时也会检查过期状态。

## DeepSeek 临时封禁

依据当前官网脚本的结构化信号处理：

- API `code=50006`，`data.end_at` 为 Unix 秒时间戳。
- 对话错误 `code=5` / 对话业务错误，`data.mute_until` 为 Unix 秒时间戳。
- 用户资料中的 `chat.is_muted` / `chat.mute_until`。
- `code=40012` 为无自动恢复时间的账号封禁，需人工检查。

程序仅解析这些上游错误或用户状态字段，**不会根据模型生成的文字、代码示例或工具参数停用账号**。有可信未来时间则定时恢复；无可信时间则暂停并提示人工处理，不猜测解封日期。界面中的人工解除按钮有确认步骤，也不会修改凭据有效性。

流式及非流式均会记录暂停，但不会自动重发刚才失败的生成。接口尚未开始输出时，临时封禁返回 429；有恢复时间时带 `Retry-After`。已经开始输出的流通过错误结束，不能改写已经发出的 HTTP 状态。

协议来源：[DeepSeek 官网](https://chat.deepseek.com/) 发布的 [当前主脚本](https://fe-static.deepseek.com/chat/static/main.2029023598.js)，核对日期 2026-09-06。

## Arena 模型限额

- 每个账号、每个原生模型 ID、文本/生图模式分别记录，不用显示名称混淆模型，也不停止同账号的其他模型。
- 按用户提供的限制，为当前账号目录中真实可选的 **Seedream 5.0 Pro 生图**设置滚动 **5 次/小时**的保守默认。当前官网公开目录没有可核验的固定次数字段，因此这不是对所有账号额度的保证。
- 官网返回的模型恢复时间、HTTP 429、`RateLimit-Reset` 和 `Retry-After` 会用于冷却；没有可信时间时暂缓 60 秒，不自动发送生成。
- 达到已知额度时，本机在发送前拦截并返回 429 和恢复等待时间；重启不会重置已计入的次数。
- 并发请求先原子保存预留。只有明确在提交前失败才退回；超时、断线、退出等结果不确定情况保守计数，避免重复发送。
- 其他没有明确固定额度的模型不虚构次数限制，也不会因为本机历史计数而人为设置 30 天上限。

网页登录说明及支持范围见 [Arena 文档](providers/arena.md)。

## 验证方式

自动测试使用本地构造的封禁和额度事件，覆盖关闭排除、到期恢复、重启持久化、手动关闭优先、同会话绑定和 429 等路径；不故意触发真实账号封禁，也不连续耗尽真实额度来做测试。

本机生产入口检查使用 `scripts/smoke-app.cjs` 的隔离资料目录。真实账号检查只在显式运行 `scripts/check-local.ps1 -Live ...` 时发送少量请求，不进行自动重试。
