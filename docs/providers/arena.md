# Arena 网页供应商

## 登录和模型同步

在供应商页面选择 **Arena** 并添加账号。程序使用电脑上已安装的正式 Chrome/Edge，以及 Chat2API 自己创建的独立浏览器资料目录；请在出现的窗口中自行登录或完成验证。不会附加到个人浏览器，不导入第三方 Cookie，也不会导出网页登录凭据。

登录成功后默认用账号邮箱命名，并读取当前账号实际可选的模型；也可以在供应商页面刷新模型。尚未登录时不把历史排行榜或公共页面快照作为可用模型发布。

- 文本：`arena/text/<当前公开模型名>`
- 生图：`arena/image/<当前公开模型名>`

模型名称和供应情况以账号当前网页为准，不硬编码过时的 Seedream 列表。网页验证和模型访问限制仍然有效；遇到需要验证的响应时返回 `action_required`，需要用户在该账号窗口操作后自行重试。

### 登录入口核对（2026-09-06）

当前仍打开 [Arena 文本直聊页面](https://arena.ai/text/direct)。匿名检查返回 200，最终地址不变；页面的 SEO canonical 是 `/direct`，不代表必须改用一个独立登录地址。官网通过页内登录弹窗登录，Google 按钮再进入官方 `/nextjs-api/sign-in/google` 并保留返回地址。程序继续让用户在正式浏览器中点击官网登录，不直接拼接第三方登录流程，也不修改已成功使用的入口。[官方登录脚本](https://arena.ai/_next/static/chunks/2gl8nxrub-tu6.js?dpl=dpl_6hobeq61sqzpfut9MJohPTWiZUR1)

## 每个账号、每个模型的额度

- `seedream-5.0-pro` 默认使用**滚动一小时最多 5 次**，这是用户指定的保守默认值，**不是声称官网保证所有账号均有该额度**。只有当前登录账号的真实模型目录匹配该名称后，才绑定其原生模型 ID；不硬编码历史 ID。
- 额度按账号 ID、原生模型 ID 和文本/生图类型分别记录。不同别名映射到同一原生模型时共享对应额度；一个模型限流不会停用整个账号，也不会影响另一个模型或账号。
- 官网当前公开模型目录未提供可验证的固定次数/窗口元数据，因此其他模型不编造统一的 5 次/小时限制。网页的 `rateLimitedUntil` 和上游 429 的 `RateLimit-Reset`（秒级时间戳）、`Retry-After`（秒数或日期）优先形成冷却；没有有效时间的 429 使用一分钟保守冷却，而非永久禁用。[官方限流处理脚本](https://arena.ai/_next/static/chunks/1-a_k6ztn45_0.js?dpl=dpl_6hobeq61sqzpfut9MJohPTWiZUR1)
- 满额或冷却时返回 429 和重试时间，不自动重发生成。即使上游按更广的范围限流，本地也只冷却当前账号的当前模型，不擅自停用账号。
- 发送前先把预留记录原子写入应用数据目录下的 `arena-rate-limits/ledger-v1.json`；重启不会清空额度。只有明确证明尚未提交的网页前置步骤失败才退还，提交后的失败、断线、取消、进程退出或状态不明都保留计数，避免重复消耗。已知限制仅保留对应滚动窗口的计数；未知限制的模型不累计本地次数，只持久化实际遇到的冷却，新确认的固定限制从观察时开始计。
- 额度文件损坏或不可写时 Arena 请求返回 503，其他供应商不受影响；修复应用数据目录后需要重启程序，不会悄悄清空记录继续提交。文件不保存 Cookie、Token、邮箱或提示词。

## API

模型发现使用 `GET /v1/models`，文本使用 `POST /v1/chat/completions`（或 Claude Code 的 `POST /v1/messages`）。首轮系统/工具说明只发一次，后续复用原 Arena 会话，只提交新用户输入和工具结果。不同账号不共享浏览器环境；同一账号同时只允许一个请求，繁忙时返回 409。

生图使用 `POST /v1/images/generations`，请求示例中的模型名须替换为模型列表的真实名称：

```json
{
  "model": "arena/image/<从模型列表选择>",
  "prompt": "白色背景上的一个蓝色正方形",
  "n": 1,
  "response_format": "url",
  "size": "auto"
}
```

返回 OpenAI 风格的 `created` 和 `data: [{url}]`。当前仅支持单张文生图、URL 输出和网页自动尺寸；不支持图片编辑、批量生成、`b64_json` 或指定分辨率，不会默默忽略这些参数。文本接口不接受图片附件；生图模型也不能作为文本模型使用。

## 验证和故障处理

- 使用 `scripts/check-local.ps1 -ArenaLogin` 完成独立窗口登录与模型同步。
- 使用 `scripts/check-local.ps1 -Live -Arena` 显式请求两轮文本续聊及一张图片；生成不自动重试。
- 只有网页流有有效终止标记且完整关闭才算成功；连接截断不会伪造完整回复。
- 退出应用时关闭其自身管理的浏览器连接；持久资料目录保留以维持登录。不要手动移动或替换资料目录。
- 接口或网页登录状态变更可能需要更新适配器。模拟协议测试通过不等于所有账号、所有模型均已实测。

协议依据：2026-09-06 的 [Arena 官方页面](https://arena.ai/text/direct) 及页面发布的脚本；已核对新会话 `create-evaluation`、续聊 `post-to-evaluation` 和 `direct-battle` 模式。调试证据保留在项目 `.audit-cache/arena-audit/`，不包含账号凭据。

此次登录入口和限流的匿名核对、哈希及最小片段另存于 `.audit-cache/arena-rate-limit-evidence/`。只读取公开页面和脚本，未打开账号资料目录、发起登录或生成。
