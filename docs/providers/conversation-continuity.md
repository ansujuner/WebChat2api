# 网页端多轮续聊

本次修复覆盖 DeepSeek、GLM、Kimi、MiniMax、MiMo、Qwen、Qwen AI、Z.ai、Perplexity 的网页适配器。

## 默认行为

- 新对话的第一条消息创建网页会话，并记住该网站返回的会话 ID 和回复游标。
- 下一轮复用同一个网站会话、同一个账号和同一个实际模型，只发送新增的用户消息或工具结果。
- 例如第一次发送 `你好`，下一轮发送 `今天天气怎么样`，网页收到的第二次输入就是 `今天天气怎么样`，不包含上一轮问答。
- 单条普通文本不再额外包装成 `User: 你好` 或 `[User] 你好`。
- 首轮系统提示和工具定义只注入一次，后续仍保留工具调用解析能力。
- 不再在每轮回复结束后删除被保留的网页会话，也不再自动重试可能已经提交过的生成请求。

## 两种客户端都支持

### 1. 普通 OpenAI 客户端：继续发送完整 messages

客户端无需修改。代理会对已完成的问答做严格前缀匹配，确认是同一个对话后，自动剥离已发送的上下文。**客户端到代理**仍可能发送历史，但**代理到网页**只发送增量。

如果客户端编辑、裁剪或改写历史，导致无法严格匹配，则它不再是已知对话的续轮。没有指定会话 ID 时，这会作为新对话初始化。要明确重开，可传 `new_conversation: true`。

### 2. 只发送当前输入：带上代理会话 ID

每次成功响应均带有 `X-Chat2API-Session-ID` 响应头，非流式 JSON 还带有 `session_id`。后续请求在同名请求头或请求体 `session_id` 中带上它即可。流式请求使用响应头拿 ID。

首轮请求：

```json
{
  "model": "deepseek-v4-flash",
  "messages": [{"role": "user", "content": "你好"}],
  "stream": false
}
```

拿到返回的 `session_id` 后，第二轮请求：

```json
{
  "model": "deepseek-v4-flash",
  "session_id": "这里替换为首轮返回的 c2a- 开头 ID",
  "messages": [{"role": "user", "content": "今天天气怎么样"}],
  "stream": false
}
```

这里的 ID 是 Chat2API 的不透明句柄，不是网站 URL 中的 UUID；网站 ID、父消息 ID、Perplexity 续聊令牌只在代理内部使用，不进入请求日志。

## 隔离与失败处理

- 会话绑定已验证的 API Key 身份、连接来源、可选 `user` 和 `X-Chat2API-Client-ID`；这些身份信息应在同一对话内保持一致。多个应用共用同一 Key 时建议设置不同的 Client ID。
- 相同开场白不会把两段对话合并。若完整历史恰好对应多个会话，返回 `409 ambiguous_conversation`，需要指定会话 ID。
- 同一会话上一轮尚未结束时返回 `409 conversation_busy`。原账号不可用时返回 `503`，不会悄悄换号丢失上下文。
- 更换模型、系统提示、工具定义或对话模式时，请显式新建会话。
- 缺少真实上游游标、流截断、异常结束或客户端中断后，不会自动重放历史。结果不确定的会话会被标记，续用时返回 `409 conversation_uncertain`。
- 显式句柄过期或服务重启后返回 `404 conversation_not_found`，需要重新开始。路由索引仅保存在内存，使用会话设置中的闲置超时（默认 30 分钟），最多保留 2000 个条目；不会持久化网站续聊令牌。
- 超时释放的是本地索引，不会自动删除网页中的历史记录。原来的逐轮删除开关不再对这些被保留的会话生效。

## 边界与验证

- 如果第一条请求本身就包含旧历史，代理为了初始化新网页会话，会一次性带上这段历史；之后正常续轮不再重发。
- 工具结果会作为本轮新增内容发送；系统设置和工具定义并非用户当前输入，因此仅首轮做必要初始化。
- 自定义的普通 OpenAI 兼容 API 仍按无状态 API 工作，不裁剪其历史；它们不接受网页续聊句柄。
- 每轮仅支持一个候选回复（`n=1`）。无法仅凭一条新消息判断它属于哪段对话，因此只发当前输入的客户端必须带会话句柄。
- 自动测试使用隔离的模拟账号、上游响应和本机 HTTP 服务，覆盖多轮增量、游标、隔离、工具、流式/非流式和失败路径；不代表已经用真实账号验证各网站的当前服务端协议。网站再次改版时应按错误结果修正协议，不能通过新开会话和重发历史掩盖问题。
