# 账号真实测活（v1.5.1）

“验证凭据”检查登录信息是否有效；**“测活”会通过指定账号真实发送一条文字消息**，只有收到完整、非空的正常助手回复才通过，不把 HTTP 200、空回复、未完成流或工具调用当成成功。

## 在哪里使用

- 供应商总览：**全部账号测活**。
- 某个供应商的账号列表：**批量测活**，只检查该供应商的账号。
- 账号卡片或账号详情：**测活**，只检查这个账号。

结果面板显示每个账号的成功、失败、跳过或取消状态，以及所用模型、时间、耗时和安全的原因提示。结果保留在本次应用运行期间，重新进入页面可以查看；重启不会自动重新测活。

## 请求和调度规则

- 每个账号只发送一句：`你好，请只回复 OK。` 不加入工具说明、系统前置提示或原有对话上下文。
- 使用该供应商已配置的一个文字模型，优先轻量模型；Arena 使用可用目录中的文字模型，不调用生图模型。通过只说明**这个账号在这次请求、这个模型上正常返回**，不代表所有模型、额度或工具能力都通过。
- 每个请求直接绑定指定账号，不经轮询挑选其他账号，不换模型重试，也不自动重发。
- 批量按顺序执行，跳过手动关闭的账号/供应商，以及冷却中、已达每日额度或已知封禁的账号。
- 显式单账号测活可检查手动关闭或被旧凭据检查标记为错误/过期的账号，但不会启用它。冷却、已知封禁和额度限制仍然有效，不因点击测活而绕过。
- 测活通过不会改写凭据状态或解除冷却。若官网在请求中返回新的封禁信息，原有自动暂停保护仍然生效。网络错误不能证明账号永久失效，因此普通失败不会自动删除或永久关闭账号。
- 成功请求计入本地请求次数。Arena 等上游额度照常消耗；测活不是免费额度通道。

## 停止与超时

**停止后续测活**只取消排队中的账号，当前请求可能已经提交，无法承诺撤回。程序等待当前请求真实结束后才允许下一批，不会超时后偷偷并发发第二次。

单次测试在 90 秒时发出取消信号。Arena、通用 HTTP 请求及已收到的网页响应流支持取消；部分供应商的登录刷新、建会话或轮询阶段仍需要等待其实际超时，因此界面可能继续显示正在结束当前请求。迟到的回复不会把已超时测试改成通过。

网站协议不一定支持硬性输出 token 上限；本程序会请求简短回复并限制读取大小，不保证官网按 `max_tokens=32` 截断。测活可能在官网留下一个新的短对话，不会删除或续写你的其他聊天。

## 无需启动代理

桌面测活通过本地受信任的程序接口调用同一供应商适配器，不依赖 HTTP 代理的监听端口、访问密钥或管理接口开关。

Windows 也可显式从当前应用发起全部账号测活：

```powershell
.\scripts\check-local.ps1 -Live -Accounts
```

报告写入已忽略的 `artifacts/proxy-accounts-probe.json`，只包含供应商、模型、结果和时间等摘要，不导出账号邮箱、凭据或官网原始回复。报告超时不代表请求没有发送；不要立即重复发起。
