# 深度检查与重新部署（2026-09-06）

本轮在已有工具调用、Claude Code、网页续聊与 Arena 适配基础上继续检查。以下区分实际修复、隔离测试和真实账号验证，不把单元测试通过等同于所有供应商可用。

## 修复清单

| 范围 | 确认的问题与修复 |
|---|---|
| 自动重启 | 增加 `scripts/restart-local.ps1`：先正常退出，超时才逐个重新核验并结束本项目 Electron 进程；保留账号和配置，不结束个人浏览器或其他软件。 |
| 代理管理 | 停止/重启接口原先等待关闭承载当前请求的服务器，可能相互等待。现在先返回 202，再执行并记录结果，重复操作返回冲突。 |
| 并发统计 | 从请求开始时的旧账号快照累加会丢计数；改为完成时同步读取最新计数。生图也计入账号和请求统计，已删除账号不会复活。 |
| 上游错误 | 非流式空响应、错误对象或不完整回复不再伪装成功；普通上游 400 不再误伤账号状态。 |
| 流与续聊 | 无效 UTF-8、错误帧、异常角色/工具数据和截断流不提交可复用会话；通用流解析状态按请求隔离，不在 EOF 伪造结束。 |
| 工具兼容 | 重复工具 ID、代码围栏中的示例调用和异常终止补充校验。清除会话后，旧请求的迟到取消不能恢复已删除会话。 |
| 会话匹配 | 相同历史但系统/工具策略不同，不再产生错误的会话歧义；不支持的流式多选在请求上游前拒绝。 |
| 模型映射 | 精确规则与单星号通配符规则按统一优先级匹配；转发、账号选择、模型详情保持一致，Arena 命名空间不借用其他供应商。 |
| 配置保存 | IPC、配置管理器和管理 API 在写入前校验类型与结构；拒绝字符串端口、非法数值和错误嵌套对象。日志只记修改字段名，不记录 API Key 或自定义提示原文。 |
| 公共入口 | 修复存储初始化未绑定导入、路由/流处理器错误导出、旧默认提示适配器不存在的常量，以及账号工厂过时字段。 |
| 旧兼容元数据 | 补全 MiMo/Z.ai 手动凭据元数据，清除旧工具 helper 的无效死导入并明确兼容入口导出；没有更改未调用的旧提示清理分支。 |
| Arena 启动 | 等待当前网页用户及模型状态就绪，不把页面尚未加载完误判成登录失效；等待可取消，不重试模型生成。 |
| Arena 提交 ID | 新会话、用户消息和模型消息改用 UUID v7，包含毫秒时间、加密随机和单调序列；旧会话 ID、模型 ID 和浏览器资料 ID 不被重写。 |
| Arena 图片 | 大响应使用有界背压而非超过小队列就误判失败；图片诊断上限 48 MiB，其余诊断默认仍为 1 MiB。 |
| Arena 诊断 | 错误正文读取上限 64 KiB；仅输出固定阶段、HTTP 状态和白名单原因，不导出原始响应、提示词或凭据。 |

### Arena 定位证据

- 登录后从当前账号网页发现 145 个文本模型、46 个生图模型，共 191 个；重启后只读检查仍通过，无须重新登录。

- 只替换新提交 ID 为 UUID v7 后，首轮、续聊和图片均通过真实验证，确认该处修复有效。
- 已排除盲改 Content-Type、把 `direct-battle` 改成旧 `direct`、以及 Max 省略 modelAId 等无依据猜测：当前官方客户端和公开枚举支持现有构造方式，Max 不等于 battle 模式。
- 仅记录阶段和错误分类；没有为定位问题导出浏览器令牌或原始错误正文，也没有自动重复提交生成。

## 兼容边界

- 浏览器登录成功、模型目录可见不代表目录内每个模型已完成生成测试。
- 网页限制或验证仍需在账号窗口处理；程序不伪造浏览器指纹、不解决验证码、不自动重发结果不确定的生成。
- 应用内网页会话索引仍为内存状态；重启后会话索引重置，但浏览器登录资料保留。
- Arena 目前只支持单张文生图、URL 输出、自动尺寸；不提供图片编辑、批量生成或固定分辨率。
- Claude Code 适配不等于 Anthropic 原生服务；服务端工具、签名思考、精确 token 计费等不在支持范围。
- 全项目严格 TypeScript 检查仍有旧模块的遗留诊断，未将生产打包成功表述为类型检查全部通过。
- 检查覆盖已列路径，不承诺所有未知缺陷和未定义功能均已穷尽。
